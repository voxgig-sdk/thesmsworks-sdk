POST /message/flash

Operation ID: sendFlashMessage.

Authentication: API key in the header (JWT).

Request body

application/json

Property Type Required Description
ai boolean No Used to determine whether The SMS Works AI Optimiser should be used in the event that the message is just longer than the 1 or 2 credit boundary. This setting overrides the AI Optimiser configuration on your SMS Works account.
content string Yes Message to send to the recipient. Content can be up to 1280 characters in length. Messages of 160 characters or fewer are charged 1 credit. If your message is longer than 160 characters then it will be broken down in to chunks of 153 characters before being sent to the recipient's handset, and you will be charged 1 credit for each 153 characters. Messages sent to numbers registered outside the UK will be typically charged double credits, but for certain countries may be charged fractions of credits (for example 2.5). Please contact us for rates for each country.
deliveryreporturl string No The url to which we should POST delivery reports to for this message. If none is specified, we'll use the global delivery report URL that you've configured on your account page.
destination string Yes Telephone number of the recipient
metadata object No
metadata.schema object No Key/value pair that will be returned to you in the API call response.
metadata.schema.key string No key of the key/value pair
metadata.schema.value string No value of the key/value pair
responseemail array of string No An optional list of email addresses to forward responses to this specific message to. An SMS Works Reply Number is required to use this feature.
schedule string No Date at which to send the message. This is only used by the message/schedule service and can be left empty for other services.
sender string Yes The sender of the message. Should be no longer than 11 characters for alphanumeric or 15 characters for numeric sender ID's. No spaces or special characters.
tag string No An identifying label for the message, which you can use to filter and report on messages you've sent later. Ideal for campaigns. A maximum of 280 characters.
ttl number No The optional number of minutes before the delivery report is deleted. Optional. Omit to prevent delivery report deletion. Integer.
validity number No The optional number of minutes to attempt delivery before the message is marked as EXPIRED. Optional. The default is 2880 minutes. Integer.
