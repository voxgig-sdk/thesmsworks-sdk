create

POST /otp/send

Authentication: API key in the header (JWT).

Request body

application/json

Property Type Required Description
destination string No The phone number of the recipient.
length object No The length of the generated passcode. The default length is 6 characters, which will apply if this parameter is omitted. All generated passcodes are numeric. Optional.
metadata object No A JSON object of no longer than 1024 bytes, containing as many parameters as you wish, to store data for use in your application. This will be returned when you verify the passcode.
passcode string No A passcode you supply for use in the message template. This will be stored on the OTP record in our system for later verification. Optional.
sender string No The sender of the message. Should be no longer than 11 characters for alphanumeric or 15 characters for numeric sender ID's. No spaces or special characters.
template string No A template to use as the content for the message. You must include the '{{passcode}}' placeholder, which will be replaced by the generated passcode when the message is sent. Optional.
validity number No The length of time in seconds for which the generated passcode should be valid. Optional.

Responses

application/json;charset=UTF-8

Property Type Required Description

creditsUsed number No The number of credits used to send this message
messageid string No The messageid of the SMS used to send the OTP. Save this in your application to use when verifying passcodes.
messageparts number No The number of message parts used to send this message
status string No The initial status of the OTP message.
default: Error
