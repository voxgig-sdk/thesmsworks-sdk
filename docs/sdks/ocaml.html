Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

open Voxgig_struct
open Sdk_helpers

let client = Sdk_client.make (jo [("apikey", Str (Sys.getenv "THESMSWORKS_APIKEY"))])
